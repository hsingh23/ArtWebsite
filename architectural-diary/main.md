# Architectural Diary — ArtWebsite

Narrative history of the site's architecture. Decision details live in
`decisions/`; commit-level facts live in `../CHANGELOG.md`.

## Day one: 2025-05-07 (all six original commits)

Everything happened in a single day. The repository was initialized on GitHub
with scaffolding only (`.gitignore` + `.gitattributes`, commit `2c5cbc4`,
originally "Initial commit"). Minutes later the entire site landed in one
import (`4c4cce5`, originally "Website initial"): a Mobirise v6.0.1 export
containing the one-page portfolio, the `project.mobirise` builder source, and
roughly nine thousand lines of vendored libraries and images.

The site itself was not designed by hand — `project.mobirise` records that it
was generated by Mobirise's AI assistant from the prompt *"Artist website,
with portfolio, contact and list of services"* using image search term
*"artwork"*, on the `startm5` theme. The bones of the site therefore come from
a template intelligence: hero with tagline, metrics, gallery, testimonials,
news, FAQ, contact — the standard portfolio arc.

Two parallel tracks then ran:

- On GitHub, the custom domain was bound by creating the `CNAME` file through
  the web UI (`91a9d26`, "Create CNAME"), pointing Pages at
  `art.paintinginbali.com`.
- Locally, the builder republished the site with the first real customizations
  (`07e0b54`, originally "contact"): the navbar Contact link switched from the
  `mobiri.se` placeholder to `mailto:art@paintinginbali.com`, and the hero's
  dark overlay was removed to brighten the background image.

Those tracks diverged and were reconciled by a merge (`30cf03f`), which pulled
the CNAME into local history — the repo's only merge commit.

The day's last act (`ce06ea8`, originally "updates") corrected the homepage
stats from template exaggeration (7 years active, 300+ works sold) to the
artist's real figures (2 years, 30+) — a small diff with a clear purpose:
stop publishing inflated numbers.

## State after day one

A complete, deployed, static portfolio. Architecture flatlined at "one HTML
file plus assets" — intentionally (see decision 001). The notable open
threads, all deferred:

- Placeholder `mobiri.se` links throughout (nav, buttons, socials, footer).
- Template filler copy: lorem-ipsum intro, "Intro with video" heading,
  placeholder phone/address, template testimonials and partner logos.
- Mixed branding: "Rossi Art" (hero) vs "Painting in Bali" (navbar/domain)
  vs the "Antonio Rossi, Chicago" persona in the about text.
- Contact form dependent on the Formoid/Mobirise backend.

## 2026-09-08: documentation and history hygiene

After 16 months of dormancy, the repository received a messages-only history
rewrite (vague subjects → conventional commits; trees untouched; forced with
lease) and this documentation set: README, AGENTS.md, CHANGELOG, the diary,
and a one-shot recreation `prompt.md`. No site content changed.
